How the forecast was evaluated

Compare last observation, ordinary least-squares trend, and damped trend (0.8 damping). Select the lowest validation mean absolute error (MAE) on expanding windows for 2018–2020; evaluate separately on 2021–2023. Refit the chosen model on 2015–2023. Shading is a sensitivity band based on the largest held-out absolute error multiplied by √horizon. It is not a calibrated confidence interval. Only three held-out years are available. Source classification and questionnaire changes limit interpretation, particularly for correspondence and transactions.

Evidence you can trace

National survey estimates describe household mail usage. Markets describe mail purpose; they are not interchangeable with USPS product classes. These source tables do not support filtering by every named postal product.

Long-term series uses the latest available estimate for each year in extracted aggregate Table E.2 data. It preserves revisions but does not harmonize all questionnaire and classification changes. For a controlled comparison, use a single report edition. Market categories overlap; do not add them to reproduce Total.

The 2024–2025 tables are pieces per household per year. Earlier summary tables use billions of pieces. A separate report for 2011 has not been downloaded; 2011 values are available as historical comparisons in later reports. The 2021 file has image-based table pages; its figures are supplied by later reports and identified accordingly.
