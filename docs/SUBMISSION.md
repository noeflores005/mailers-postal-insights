# Project information

**Team:** Mailers

**Project title:** Postal Insights: Exploring American Household Mail Usage

**Use case provider:** USPS Office of Inspector General

**Short description:** Mailers turns annual USPS household mail reports into a local dashboard for exploring historical mail markets, comparing household demographics, reviewing source-linked NLP evidence briefs, and evaluating forecast scenarios. Every plotted value retains its report edition and PDF page. Unit changes and historical revisions remain visible so analysts can assess comparisons before using them.

**What to demonstrate:** 21 historical annual observations per market (2003–2023); newer 2024–2025 results within their own report editions; 19 demographic groups from FY2025; offline extractive TextRank summaries; forecast scenarios with separate validation and held-out evaluation; source reports and CSV downloads.

**Delivery:** Local folder or ZIP; open index.html. No public deployment or account required.

**Technology:** Python data preparation and statistical models; HTML, CSS and JavaScript dashboard; TextRank-style extractive NLP; standard-library optional local server.

**Honest limits:** Forecasts are frozen at 2023 and use aggregate units; classification changes are not fully harmonized. Demographics are marginal FY2025 comparisons. Summarization is extractive, not a generative LLM. Preparation-time reduction has not been measured.
